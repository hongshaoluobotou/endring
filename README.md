# 终末之环 (End Ring)

一件为 Minecraft 26.2 打造的 Fabric 模组。核心是一枚强力饰品「终末之环」：戴上便无法取下，赋予佩戴者近乎不朽之力，并在生命耗尽时召唤终末巨龙的死亡。

## 终末之环 · 完整功能

### 绑定
- **绑定诅咒**：无法脱下，死亡也不掉落。

### 防护
- **护甲**：基础 20，血量 <60% → 22，<40% → 24，<20% → 24.9。
- **完全免疫**：摔落 / 火焰 / 爆炸 / 窒息 / 缺氧 / 仙人掌接触等。
- **减伤 80%**：仙人掌 / 冰冻 / 近战 / 远程 / 魔法。
- **饥饿伤害**至少 3 点（不会被饿死于 0）。

### 越弱越强
- **受伤时**：抗性 IV，持续 30 秒。
- **力量**：血量 <40% → I，<30% → IV，<20% → IX，<10% → XVI。
- **回血**：受伤 <20% → 再生 I，<10% → 持续再生 II。

### 机动与实用
- **创造飞行**，冲刺 / 升降时持续加速。
- **夜间夜视**，水下潮涌效果。
- **徒手创造挖掘**。
- 敌对生物默认对佩戴者中立，除非被其主动攻击。

### 图腾续命
- 致命伤害消耗 **1 图腾**续命，随机回复 50%–100% 生命并获得一次性吸收护盾。
- 图腾数以**耐久条**显示；每 30 秒回复 +1，上限 **8**。
- 附有**耐久（Unbreaking）魔咒**时有几率不消耗图腾。
- 图腾**耗尽**时触发终末巨龙死亡演出。
- 佩戴的环模型随图腾数变化：满值完好 → 少于半数缺损 → 归零残破。
